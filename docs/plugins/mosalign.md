# Mosaic Alignment (Mosalign)

Beamline-specific 2D motor-scan tool with image stitching and tomoscan
integration. Ships as part of the bl32ID plugin pack — see the
[Mosalign section of the bl32ID docs](../beamlines/bl32ID.md#mosalign).

Source: [src/pystream/beamlines/bl32ID/mosalign.py](../../src/pystream/beamlines/bl32ID/mosalign.py).
